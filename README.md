# KITA WMS TCC

## Dependências do Projeto

Este projeto utiliza as seguintes dependências principais:

- Express: framework para criação da API e servidor web
- Nodemon: reinicia automaticamente o servidor em desenvolvimento
- PostgreSQL (pg): cliente para conexão com banco de dados PostgreSQL
- bcryptjs: criptografia de senhas
- jsonwebtoken: geração e validação de tokens JWT
- dotenv: carregamento de variáveis de ambiente a partir de um arquivo .env

### Dependências instaladas

"dependencies": {

### Observação

Essas bibliotecas foram instaladas para apoiar o desenvolvimento do backend, autenticação de usuários, conexão com PostgreSQL e gerenciamento de variáveis de ambiente.

Qualquer colaborador ou visitante do repositório pode usar esta informação como referência inicial para entender a base tecnológica do projeto.
